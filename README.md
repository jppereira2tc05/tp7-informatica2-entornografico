Utilizar Processing para desarrollar una interfaz gráfica de control de E/S de Arduino que tenga las siguientes características. 
Ver figura.

Se desarrollará el programa que corra en Arduino de modo de Activar los Leds según el Pulsador que sea oprimido y además pueda manejar las comunicaciones en ambos sentidos con la PC que muestra las gráficas indicadas en los puntos anteriores.
